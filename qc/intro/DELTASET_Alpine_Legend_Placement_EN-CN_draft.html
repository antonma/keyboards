Purpose. This guide gives the artwork designer who builds the print file the exact position of every legend, dot-matrix icon panel and special cap, grouped into four clusters. These positions are binding for the print file — please build to them.

If anything in this guide looks like it will not work with your print process, please ask before producing the print file. Do not silently change a position.

用途。本指南为制作印刷文件的设计师提供每个字符、点阵图标面板与特殊键帽的 准确位置，分为四个分组。文件中的这些位置是约束性的——请按此制作。

如果本指南中的任何内容与你们的印刷流程不符，请在制作印刷文件之前提出问题。 请勿自行改动位置。

Anchor rule — please read this first / 定位基准 —— 请先读这一段

The anchor is a reference line — the top of the character block (cap-height line) or the bottom (baseline) — measured from the printable face edge. It is not the visible outline of each individual glyph or dot-matrix panel.

Characters like a minus sign, an underscore, “²”/“³”, a tilde, or an umlaut naturally have a different ink outline than a letter like “M” — they sit correctly on the reference line even though their outline looks shorter, taller, or shifted. That is normal font behaviour, not a placement error.

Please align every legend and icon panel to the offset numbers in the tables below, not to how the individual glyph outline “looks” centred.

定位基准是一条参考线——字符块的顶部（字高基准线）或底部（基线）—— 从键帽可印刷表面边缘量起。不是每个字符或点阵图标面板本身的可见轮廓。

减号、下划线、上标“²”/“³”、波浪号或变音符号的 墨迹轮廓自然会和字母“M”不同——即使轮廓看起来更短、更高或有偏移， 它们在基准线上的位置仍然是正确的。这是字体本身的正常表现，不是定位错误。

请按下方表格中的边距数值对齐每个字符与图标面板，不要按单个字符轮廓“看起来 居中”去调整。

1 Main legends  /  1 主字符

涉及按键：字母、变音字母（Ä Ö Ü）、数字排、小键盘数字、ß、标点/特殊符号 （含井号备用变体）。（F1–F12 和 Esc 为点阵面板，见第3组。）

Factory floor QC  /  产线品检

产线工人使用另一份专为工人制作的、带插图的品检清单，按相同的四个分组核对已印刷的 键帽（并非本文件）。如果打样结果与上述边距数值不符，请在批量生产前提出。
